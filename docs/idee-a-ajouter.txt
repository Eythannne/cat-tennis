- Chatbot d'aide SANS IA, par mots-clés (ajouté le 14/11/2026) — version retenue

  --> Admin : nouvelle page "Chatbot" pour gérer des fiches :
      - question type      (ex : "Comment s'inscrire au club ?")
      - réponse            (ex : "Téléchargez la fiche d'inscription sur la page Tarifs...")
      - mots-clés          (ex : inscription, inscrire, adhérer, adhésion, licence, rejoindre)
      - lien optionnel     (ex : "Voir les tarifs →")
      - ordre / afficher en bouton "question fréquente" ou non
  --> Site public : bulle en bas de l'écran avec
      - des boutons de questions fréquentes (S'inscrire, Tarifs, Réserver un court, Horaires...)
      - un champ de recherche libre
  --> Recherche :
      - nettoyer le texte : minuscules, sans accents, sans les petits mots (je, veux, mon, le...)
      - tolérer les variantes (inscrire / inscription / inscriptions)
      - donner des points à chaque fiche selon les mots-clés trouvés
      - afficher la meilleure réponse + 2 ou 3 suggestions ("Vous cherchiez peut-être : ...")
      - rien trouvé : "Posez votre question au club" + lien vers le formulaire de contact
  --> Réponses "vivantes" : certaines fiches reprennent les vraies données du site
